# Claude Code: дополнения

Общие правила проекта (контракт FBO, Git, тесты, наблюдаемость) — в AGENTS.md выше. Здесь только то, что специфично для Claude.

- Перед изменениями смотреть `git status` и существующий diff; в рабочем дереве есть чужая незакоммиченная работа, её не трогать и не откатывать.
- Не менять бизнес-контракты и формулы без одобрения Product Owner.
- Для сложных задач сначала составить план.
- Не запускать дополнительных агентов без необходимости.
- Минимальный объём изменений и целевые тесты вместо полного набора.
- Не делать commit, push и финализацию без отдельного явного разрешения в последнем сообщении.
- Модульные правила: `.claude/rules/` (БД и миграции, финансы и склад, UI продавца). Исходные правила команды лежат в `.agents/rules/`, это основной источник.
