# ZAMK Audit Workflow

Workflow для безопасного аудита, анализа архитектуры, поиска проблем или ревью кода без внесения изменений.

## 1. Preflight
- Запустить skill `zamk-preflight` для проверки текущей ветки, HEAD, незавершённых dirty-файлов и stashes без изменения репозитория.

## 2. Inspect Only
- Выполнять исключительно чтение и анализ кодовой базы, схем БД, логов и истории коммитов.
- Запрещено изменять продуктовый код, тесты, конфигурации или миграции (`apps/`, `backend/`, `packages/`, `migrations/`).
- Запрещено запускать модифицирующие команды и деструктивные тесты.

## 3. Report Evidence
- Сформировать объективный отчёт с доказательствами из кодовой базы (пути к файлам, номера строк, выдержки).
- Оценить влияние на архитектурные границы и соответствие правилам `zamk-core`.

## 4. Stop
- Остановить выполнение сразу после предоставления отчёта.
- Не начинать правки, не создавать коммиты.
