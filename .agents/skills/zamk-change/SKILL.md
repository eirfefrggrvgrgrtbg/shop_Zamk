# ZAMK Change

Инструкции для безопасного внесения изменений.

## Implement Declared Scope
- Реализовать строго согласованный скоуп задачи, следуя глобальным правилам в AGENTS.md.
- Не модифицировать файлы вне скоупа задачи.
- Соблюдать FBO модель и границу ответственности.

## Relevant Checks
- Выполнить релевантные существующие проверки по затронутым компонентам (npm run check:seller, check:admin, test:backend, test:migrations).
- Соблюдать правило остановки: при первом реальном FAIL последующие обязательные проверки не запускаются (NOT RUN).
- Контроль git diff: используйте git diff --check для выявления пробельных ошибок.

## No Commit / No Push
- Запрещено выполнять `git commit` и `git push`.
- Не добавлять файлы в индекс через `git add .` / `git add -A`.

## Concise Report
- Вернуть краткий технический отчёт: статус проверок, изменённые файлы.
